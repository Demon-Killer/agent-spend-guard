# 用户访谈问题

目标：

确认 AgentSpendGuard 是否解决真实痛点，而不是只做了一个工程上可行的工具。

## 访谈前提

先让用户知道：

- 这是本地工具。
- 用户自带 OpenAI/OpenRouter Key。
- 默认不保存 prompt。
- 当前是早期 MVP。

## 核心问题

1. 你现在主要用哪些 AI 编程工具？
2. 你是否使用自己的 API Key？
3. 你每月大概花多少钱在 AI coding API 上？
4. 你是否遇到过 Agent 循环调用、重复重试或意外高账单？
5. 你现在如何知道某个项目花了多少钱？
6. 你是否愿意在 AI 编程工具和模型服务之间加一层本地代理？
7. 哪个功能对你最有价值？
   - 项目级预算
   - 每分钟请求限制
   - CSV 导出
   - Dashboard
   - 不保存 prompt
   - 本地自托管
8. 哪个点会让你不愿意使用？
9. 你希望优先支持哪个工具？
10. 什么功能会让你愿意付费？

## 付费验证问题

1. 如果 Pro 版一次性 $19，你会买吗？
2. 如果 Team 自托管版 $99/年，你觉得贵吗？
3. 你更喜欢一次性买断还是订阅？
4. 你愿意为什么功能付费？

## 结束问题

1. 你愿意继续试用下一版吗？
2. 你愿意推荐给其他 AI coding 用户吗？
3. 你能介绍 1 个也有类似痛点的人吗？
