# 商业模式

## 原则

不通过 token 倒卖赚钱。

赚钱点应该是：

- 成本安全。
- 成本可见。
- 自动化控制。
- 自托管部署便利性。
- 团队协作和审计能力。

## 版本设计

| 版本 | 价格 | 范围 |
| --- | --- | --- |
| Free | 免费 | 本地单用户、基础代理、单项目 |
| Pro | 一次性 $19 | 多项目、CSV 导出、高级规则 |
| Team Self-hosted | $99-$299/年 | 共享配置、审计记录、团队用量 |
| Hosted Cloud | 后期再做 | 给不想自托管的团队使用 |

## 用户为什么付费

用户不是为“更便宜的模型”付费，而是为这些结果付费：

- 避免意外账单。
- 看清项目级花费。
- 不把代码 prompt 交给陌生云服务。
- 能在本地做硬熔断。
- 团队可以按项目或虚拟 Key 做成本归因。

## 第一笔收入假设

最容易成交的首批用户：

- 重度使用 Claude Code、Codex、Cursor、Cline 的独立开发者或小团队。
- 已经遇到或担心 API 费用失控。

首个可测试价格：

- Pro 一次性 $19。

## 后续扩展

验证后再考虑：

- Slack 或 Discord 告警。
- 团队 Dashboard。
- Git repo 维度成本归因。
- Pull Request 或 branch 维度成本归因。
- 托管 Dashboard + 本地 Relay。
