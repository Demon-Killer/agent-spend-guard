# 产品定位

## 产品名称

暂定名：AgentSpendGuard

中文名：AI Agent 成本防火墙

## 一句话定位

AgentSpendGuard 是一个自托管 LLM Gateway（大模型网关），专门防止 AI 编程工具失控消耗 API 预算。

## 名词解释

- BYOK：Bring Your Own Key，自带 API Key。用户使用自己的 OpenAI、Anthropic、Gemini 或 OpenRouter API Key。
- LLM Gateway：大模型网关。位于 AI 工具和模型服务商之间，负责转发、预算、日志和熔断。
- Self-hosted：自托管。用户部署在自己的电脑、服务器或公司内网。
- Kill Switch：熔断开关。当预算超限或调用异常时自动阻断请求。
- Virtual Key：虚拟 Key。AgentSpendGuard 本地生成的 key，用来映射项目、工具和上游 provider。

## 不是什么

AgentSpendGuard 不是：

- OpenRouter 替代品。
- 公共 token 中转站。
- 低价 API 套利平台。
- 通用 AI 平台。
- 工作流编排平台。
- Prompt 管理平台。

## 是什么

AgentSpendGuard 是：

- 本地优先的 AI Coding 成本防火墙。
- 项目级 AI 花费统计工具。
- BYOK 用户的自托管网关。
- AI Agent 的预算硬限制器。
- 一个可以从小工具逐步长成团队产品的开发者工具。

## 差异化

| 维度 | 选择 |
| --- | --- |
| 主要用户 | AI 编程工具用户 |
| 核心价值 | 成本可见和预算保护 |
| 部署方式 | 本地优先，自托管优先 |
| 数据处理 | 默认不保存 prompt 内容 |
| 变现方式 | 工具授权、团队授权，后期再做托管版 |
| 竞争策略 | 比通用网关更窄，更容易讲清楚价值 |
