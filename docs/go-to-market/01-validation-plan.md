# 验证计划

## 3 天验证

### Day 1

创建 landing page 文案：

> Stop AI coding agents from burning your API budget.

中文含义：

> 防止 AI 编程 Agent 烧光你的 API 预算。

页面包含：

- 问题描述。
- 简短 demo GIF 占位。
- Waitlist 表单。
- GitHub 链接占位。

### Day 2

构建 demo：

- 本地代理。
- 一个 OpenAI-compatible 上游 provider。
- 一个项目。
- 每日预算设置为 $1。
- 超预算返回 `402`。

### Day 3

发布并寻找试用用户：

- GitHub。
- Hacker News：Show HN。
- Reddit：r/ClaudeAI、r/OpenAI、r/SideProject、r/LocalLLaMA。
- X 上回复 Claude Code、Codex、Cursor、Cline 相关讨论。

## 验证指标

不要先优化 star。

主要指标：

- 5 个用户愿意把自己的 API Key 接入工具试用。

次要指标：

- 20 个 waitlist 邮箱。
- 3 个用户反馈真实花费痛点。
- 1 个用户询问 Pro 或团队功能。

## 证伪信号

出现以下情况要暂停或调整：

- 用户认为 provider 自带账单已经足够。
- 用户拒绝增加本地代理。
- 用户只关心低价 token 倒卖。
- 访谈 20 人后没有人有具体花费痛点。
