# 竞品笔记

## OpenRouter

优势：

- 统一模型访问。
- 统一账单。
- 模型和 provider 很多。
- API 对开发者友好。

相对本产品角度的不足：

- 是云平台。
- 不是专门面向 AI Coding 失控花费的防火墙。
- repo、工具、项目级成本归因不是核心产品承诺。

## LiteLLM

优势：

- 强大的通用大模型网关。
- 支持很多 provider。
- 开源。
- 偏生产基础设施。

相对本产品角度的不足：

- 范围很大。
- 对很多个人 AI Coding 用户来说过重。
- 没有围绕“防止 AI 编程账单失控”这个结果做轻量产品化包装。

## 模型服务商账单

优势：

- 官方账单来源。
- 最终费用准确。

不足：

- 通常是账户级，不是项目级。
- 无法按具体 AI 编程项目做本地硬阻断。
- 多工具共用 key 时缺少清晰归因。
